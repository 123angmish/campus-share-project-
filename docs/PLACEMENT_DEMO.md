# CampusShare — Placement & Demo Presentation Guide

CampusShare is a production-grade, two-sided peer-to-peer campus rental and marketplace platform built with **Spring Boot 3 (Java 21)**, **PostgreSQL/H2**, **Razorpay**, **Flyway**, and **React 18 + Vite**.

---

## 🎯 Core Concept: Dual-Sided Marketplace

In CampusShare, **every registered student has full buyer AND seller/lender capabilities simultaneously**.
There are **no separate permanent buyer or seller roles**.
A single logged-in student can:
1. List their own idle items (calculators, textbooks, lab coats, cameras, sports gear) for rent or direct sale.
2. Browse, borrow, and buy items listed by other students across the campus.
3. Track lending revenue and borrowing expenses from a unified dashboard.

### 6. End-to-End Rental State Machine & PIN Handover (`/activity`)
Demonstrate the full peer-to-peer rental lifecycle:
1. **Student A (Borrower)** requests an item for specific dates $\rightarrow$ Status: `PENDING`.
2. **Student B (Owner)** receives an in-app notification and accepts the request $\rightarrow$ Status: `ACCEPTED`.
3. **Student A** pays the rental fee + security deposit via Razorpay $\rightarrow$ Status: `PAID`.
4. **Student B** receives payment confirmation and reveals the secret 6-digit **Handover PIN**.
5. Both students meet on campus. **Student A** inspects the item and enters the PIN $\rightarrow$ Status: `ACTIVE`.
6. Once the rental duration ends, **Student A** returns the item and marks `"I Returned the Item"`.
7. **Student B** verifies physical condition and confirms receipt $\rightarrow$ Status: `COMPLETED`.
8. **Student B** clicks `"Release Deposit Refund"` $\rightarrow$ Razorpay refunds the security deposit to Student A!
